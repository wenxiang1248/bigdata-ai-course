# bigdata-ai-course

大数据与人工智能课程作业仓库。

## 目录结构

```
bigdata-ai-course/
├── homework/   # 各次作业（每次作业建一个子目录，如 hw1、hw2）
├── labs/       # 实验代码
├── notes/      # 学习笔记
├── .gitignore  # 忽略不需要提交的文件
└── README.md
```

## 提交作业的步骤

每次写完作业后，在仓库根目录执行：

```bash
git add .                          # 把改动加入暂存区
git commit -m "完成第 1 次作业"      # 提交并写明说明
git push                           # 推送到 GitHub
```

## 常用命令速查

| 命令 | 作用 |
|------|------|
| `git status` | 查看当前改动状态 |
| `git add .` | 暂存所有改动 |
| `git commit -m "说明"` | 提交改动 |
| `git push` | 推送到远程仓库 |
| `git pull` | 拉取远程最新内容 |
| `git log --oneline` | 查看提交历史 |
